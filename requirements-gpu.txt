# Environment pins for the CUDA/GPU setup (.venv312).

# Why the pins: torch 2.3.1+cu118 was compiled against NumPy 1.x, so it
# cannot run with NumPy 2.x ("Failed to initialize NumPy: _ARRAY_API not
# found"). That version of torch is itself required here because it's the
# newest cu118 build that works with a Pascal-generation GPU (MX330,
# compute capability 6.1). So the whole stack must stay on the NumPy 1.x
# era — the versions below are the last releases of each package that
# support numpy<2.
#
# Install torch FIRST, from the PyTorch index, then this file:
#   pip install torch==2.3.1 torchvision==0.18.1 --index-url https://download.pytorch.org/whl/cu118
#   pip install -r requirements-gpu.txt
